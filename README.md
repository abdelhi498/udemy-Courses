# كورسات مجانية — كوبونات يوديمي 100%

موقع يعرض الكورسات التي عليها خصم 100% (يوديمي أساساً، ومنصات أخرى إن وُجدت)،
ويجمعها **تلقائياً كل ساعة** من قنوات تيليجرام عامة.

- **بدون سيرفر وبدون تكلفة:** GitHub Actions يشغّل السكربت، وGitHub Pages يستضيف الموقع.
- **بدون مكتبات خارجية:** السكربت يعمل بمكتبة بايثون القياسية فقط.

## كيف يعمل؟

```
قنوات تيليجرام ──► scraper (كل ساعة) ──► docs/data/courses.json ──► الموقع (docs/)
   t.me/s/<قناة>      استخراج روابط الكوبونات
                     + تتبّع الروابط الوسيطة
                     + التحقق من الكوبون عبر يوديمي
```

1. **القراءة من تيليجرام:** كل قناة عامة لها صفحة ويب `https://t.me/s/<اسم_القناة>`
   تعرض آخر الرسائل، فلا نحتاج حساب تيليجرام ولا API key.
2. **استخراج الكوبونات:** نبحث في كل رسالة عن روابط
   `udemy.com/course/...?couponCode=...`. إذا كان الرابط لموقع وسيط (مدونة أو اختصار روابط)
   نفتحه ونبحث بداخله عن رابط يوديمي.
3. **التحقق (اختياري):** نسأل يوديمي هل الكوبون ما زال يجعل السعر 0،
   ونجلب العنوان والصورة الحقيقية للكورس. الكوبونات المنتهية تُحذف، وما لم نستطع التحقق منه
   يظهر بعلامة "غير مؤكد".
4. الكورسات الأقدم من `max_age_days` (7 أيام افتراضياً) تُحذف تلقائياً.

## التشغيل

### على GitHub (موصى به)

1. ادمج هذا الفرع في `main` (المهام المجدولة تعمل فقط على الفرع الافتراضي).
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. من **Actions → Update courses** اضغط **Run workflow** لأول تشغيل.
4. الموقع سيكون على `https://<اسم_المستخدم>.github.io/<اسم_المستودع>/` ويتحدث كل ساعة.

### محلياً

```bash
python -m scraper.scrape          # يجمع الكورسات ويكتب docs/data/courses.json
python -m http.server -d docs     # افتح http://localhost:8000
python -m unittest discover -s scraper/tests -t .   # الاختبارات
```

## الإعدادات — `scraper/config.json`

| الإعداد | المعنى |
|---|---|
| `telegram_channels` | أسماء القنوات (الجزء بعد `t.me/`). أضف أي عدد من القنوات العامة. |
| `pages_per_channel` | عدد الصفحات المقروءة من كل قناة (الصفحة ≈ 20 رسالة). |
| `max_age_days` | بعد كم يوم يُحذف الكورس من الموقع. |
| `resolve_redirects` / `max_redirect_lookups` | تتبّع الروابط الوسيطة، والحد الأقصى لها في كل تشغيل. |
| `validate_udemy` / `max_validations` | التحقق من صلاحية الكوبون عبر يوديمي، والحد الأقصى في كل تشغيل. |

## مصادر بديلة أو إضافية

| الطريقة | المميزات | العيوب |
|---|---|---|
| **صفحة `t.me/s` (المستخدمة الآن)** | مجانية، بدون حساب، سهلة | للقنوات العامة فقط، وقد تتغير بنية الصفحة |
| **Telegram API (Telethon)** | يقرأ أي قناة أنت عضو فيها، لحظي | يحتاج `api_id` ورقم هاتف وجلسة محفوظة كـ secret |
| **مواقع تجميع الكوبونات** (مثل real.discount و discudemy و courson) | كمية كبيرة وبيانات جاهزة | scraping لمواقع أخرى قد يخالف شروطها ويتعطل عند تغيير تصميمها |
| **Udemy Affiliate API** | بيانات رسمية (عنوان، تقييم، سعر) | لا يعرض الكوبونات المجانية؛ مفيد فقط لإثراء البيانات |

لإضافة مصدر جديد: اكتب دالة ترجع رسائل بنفس شكل `telegram.fetch_channel`
(`text` و`links` و`date` و`post` و`channel`) وادمج نتيجتها في `scrape.run`.

## ملاحظات

- الموقع لا يستضيف أي محتوى؛ يعرض فقط روابط المنصات الرسمية مع ذكر المصدر.
- يوديمي قد يحجب الطلبات الآلية أحياناً؛ وقتها تظهر الكورسات "غير مؤكدة" بدل أن تختفي.
