⚙️ لوحة التحكم

لوحة التحكم تحفظ التعديلات مباشرة في مستودع GitHub الخاص بالموقع، لذلك تحتاج "مفتاح دخول" من GitHub مرة واحدة على كل جهاز.

👑 صاحب الموقع: كيف أحصل على المفتاح؟
  1. افتح صفحة إنشاء مفتاح جديد.
  2. Token name: أي اسم، وExpiration: مدة طويلة.
  3. Repository access ← Only select repositories ← اختر udemy-Courses.
  4. Permissions ← اجعل Contents و Actions = Read and write (وأضف Administration = Read and write إذا أردت دعوة مستخدمين من اللوحة).
  5. اضغط Generate token وانسخ المفتاح والصقه هنا.
👥 عضو في الفريق: كيف أحصل على المفتاح؟
  1. اقبل دعوة صاحب الموقع (تصلك على بريدك أو في إشعارات GitHub).
  2. افتح صفحة إنشاء مفتاح (classic) — الصلاحيات repo و workflow محددة مسبقاً.
  3. اختر مدة الصلاحية، واضغط Generate token، وانسخ المفتاح والصقه هنا.

🔒 المفتاح يُحفظ في متصفحك فقط ولا يُرسل لأي مكان غير GitHub.
