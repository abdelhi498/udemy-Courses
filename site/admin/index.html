⚙️ لوحة التحكم

لوحة التحكم تحفظ التعديلات مباشرة في مستودع GitHub الخاص بالموقع، لذلك تحتاج "مفتاح دخول" من GitHub مرة واحدة فقط.

كيف أحصل على المفتاح؟ (دقيقتان)
  1. افتح صفحة إنشاء مفتاح جديد على GitHub (سجّل الدخول إن طُلب منك).
  2. في Token name اكتب: لوحة التحكم، وفي Expiration اختر مدة طويلة (مثلاً سنة).
  3. في Repository access اختر Only select repositories ثم اختر مستودع الموقع udemy-Courses.
  4. في Permissions افتح Repository permissions واجعل:
    • Contents ← Read and write
    • Actions ← Read and write
  5. اضغط Generate token بالأسفل، ثم انسخ المفتاح (يبدأ بـ github_pat_) والصقه هنا.

🔒 المفتاح يُحفظ في متصفحك فقط ولا يُرسل لأي مكان غير GitHub.
